## 🌟 Overview
**WALLPO XTREME PRO** is a premium, futuristic AI-powered wallpaper generation and discovery platform. Designed with an advanced dark Glassmorphism UI, ambient neon glows, and seamless mobile responsiveness, it empowers users to generate stunning 4K wallpapers using state-of-the-art open-source generative AI (FLUX.1) completely free of charge.

---

## ✨ Features

### 1. Futuristic Glassmorphism UI
- **Color Palette:**
  - Deep Black (`#080A12`)
  - Midnight Navy (`#10172A`)
  - Electric Purple (`#8B5CF6`)
  - Neon Blue (`#38BDF8`)
  - Soft White (`#F8FAFC`)
- Frosted-glass cards with blur filters and ambient lighting effects.
- Pinterest-style staggered masonry grid for wallpaper discovery.
- Fully responsive across mobile phones, tablets, and desktop displays.

### 2. Genuine Free AI Wallpaper Generator
- **Text-to-Image Generation:** Real-time synthesis powered by the FLUX.1 model.
- **AI Prompt Assistant:** 1-tap smart prompt enhancement transforming simple phrases into 4K cinematic prompts.
- **Inspire Me Tool:** Generates instant master concepts across diverse styles.
- **17 Art Styles:** Realistic Photography, Ultra-Realistic, Anime, Cyberpunk, Minimalist, Abstract, 3D Render, Fantasy, Nature, Cinematic, Digital Art, Dark Aesthetic, Space & Galaxy, Luxury, Neon Art, Vintage, Surrealism.
- **Resolution Options:** 9:16 Mobile (720×1280 / 1080×1920), 16:9 Desktop (1920×1080), 1:1 Square, 4K Ultra-HD.
- Multi-step realistic synthesis progress bar.

### 3. Interactive Phone Mockup Viewer
- Test how any wallpaper looks on a phone screen before setting it!
- **Lock Screen Mode:** Real-time digital clock, live date, and notification overlay.
- **Home Screen Mode:** Simulated mobile application dock.
- Fullscreen immersive image view.

### 5. Native Android Capabilities (`AndroidBridge`)
- **Direct Wallpaper Setting:** Apply wallpaper to Home Screen, Lock Screen, or Both screens using Android's native `WallpaperManager`.
- **Media Gallery Saving:** Automatic high-resolution export to `Pictures/WallpoXtremePro` with Android MediaStore integration.
- **System Share Sheet:** Native Android share intent for instant messaging and social sharing.
- **Haptic Feedback:** Vibrator engine trigger on user interactions.

### 6. Offline Library & Storage
- **Favorites:** Quick access to saved wallpapers.

- **My AI Creations:** Automatically records user generations.
